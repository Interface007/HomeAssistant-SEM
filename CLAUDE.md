# Claude Code Repository Instructions

These instructions apply to all files in this repository.

## Mandatory language policy

- All code comments must be written in English.
- All docstrings must be written in English.
- All inline code explanations must be written in English.

## Important exceptions

- Do not automatically rewrite user-facing text, entity labels, or localization content unless explicitly requested.
- Preserve external protocol keys and identifiers as-is.

## Editing behavior

- When modifying a file that contains non-English comments, translate the touched comments to English.
- Avoid introducing any new non-English comments.
